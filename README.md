# Simple Front-End Project

This is a basic front-end web project built using **HTML**, **CSS**, and **JavaScript**. It serves as a practice/demo project to demonstrate simple UI and interactivity using vanilla technologies.

## 🚀 Features

- Responsive design using CSS
- Basic interactivity with JavaScript
- Clean and beginner-friendly code structure

## 🚀 Running Locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
